# Fast React Pizza

A pizza ordering application built with React.

**[Live Demo](https://fast-react-pizza-silk-two.vercel.app/)**

### Tech Stack
- React
- Redux Toolkit
- React Router
- Tailwind CSS

### Features
- Browse pizza menu.
- Manage shopping cart.
- Place and track orders.
- Set order priority.

### Run Locally

```bash
npm install
npm run dev
```
